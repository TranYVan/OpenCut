# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

OpenCut is being **rewritten from scratch** (the old app lives at `opencut-app/opencut-classic`). Goal: a Rust core shared by desktop, mobile and browser, with a plugin-first architecture, an Editor API, MCP server, headless mode and in-editor scripting. Most of the repo is scaffolding — expect stubs (e.g. `apps/web/src/routes/editor.tsx`, the desktop panels) rather than real features. `changelog/*.md` describes the *classic* app's releases, not this codebase.

## Tooling & commands

Toolchain versions (moon, bun, node, rust) are pinned in `.prototools`; run `proto use` to install. Tasks are orchestrated by **moon** — projects are discovered from `apps/*` and `crates/*` (`.moon/workspace.yml`), each with its own `moon.yml`. Bun is the JS package manager (`bunfig.toml` enforces a 7-day minimum release age on installs).

```sh
moon run web:dev         # TanStack Start dev server, localhost:5173
moon run web:build
moon run web:test        # vitest run (jsdom + Testing Library)
moon run api:dev         # wrangler dev, localhost:8787
moon run desktop:dev     # cargo run (first build compiles GPUI from source — slow)
moon run desktop:check   # cargo check
moon run desktop:build   # cargo build --release
moon ci                  # what CI runs (all non-dev tasks, affected projects)
```

Single test (web): `cd apps/web && bunx vitest run path/to/file.test.tsx -t "test name"`.

CI (`.github/workflows/bun-ci.yml`) runs `moon ci` on Ubuntu, Windows and macOS — keep tasks cross-platform. Tasks marked `runInCI: false` (dev servers, `upload-logos`) are skipped.

`deploy` tasks (`web:deploy`, `api:deploy`) and the root `upload-logos` task (needs `.env.local` copied from `.env.example`) push to Cloudflare — don't run them unprompted.

## Architecture

- **`apps/web`** — TanStack Start (React 19, file-based routing in `src/routes/`, Vite 8, Tailwind v4) deployed as a Cloudflare Worker to `new.opencut.app` via `@cloudflare/vite-plugin`. `src/routeTree.gen.ts` is generated by the router plugin — never edit it. Import alias `#/*` → `src/*` (package.json `imports`). `src/components/ui/` is shadcn (style `base-mira`, Base UI primitives, hugeicons) — add components via the shadcn CLI rather than hand-writing them.
- **`apps/api`** — Elysia on Cloudflare Workers (`CloudflareAdapter`). The chain must end with `.compile()` (required for AoT compilation). `build` is `wrangler deploy --dry-run`.
- **`apps/desktop`** — Rust/GPUI app (`opencut-desktop`), the only Cargo workspace member right now. Structure:
  - `main.rs` opens a maximized window, re-renders on system appearance change. A Linux/WSL block at the top of `main` unsets `WAYLAND_DISPLAY` (WSLg's `xdg_wm_base` v1 crashes GPUI 0.2.2); it must stay the first statement because `remove_var` is only safe before any thread spawns.
  - `shell.rs` composes the four panels (`panels/`: browser, preview, inspector, timeline). Panels are `Entity`s created once in `Shell::new`, never via `cx.new` inside `render`, so they keep state across frames.
  - `theme.rs` defines shadcn-style semantic color tokens (`background`, `card`, `primary`, `sidebar_*`, …) for light/dark, cached in `OnceLock`s. Access with `window.theme().colors` via the `ActiveTheme` trait — don't hardcode colors.
  - `components/` holds shadcn-like primitives (Button, Badge, ContextMenu, Resizable, …) as `#[derive(IntoElement)]` + `RenderOnce` structs with builder methods and variant enums, re-exported `pub(crate)` from `components/mod.rs`. Mirror this pattern for new primitives.
- **`crates/`** — Rust core, each crate listed explicitly in the root `Cargo.toml` workspace members (add new ones there) with `check`/`test` moon tasks (`moon run editor:test`).
  - `time` (`opencut-time`): integer-tick `MediaTime` (120,000 ticks/s), `FrameRate`, timecodes. Ported from the classic app.
  - `model` (`opencut-model`): project document, serialized as the classic app's storage v31 JSON (camelCase, `toISOString` timestamps) so classic projects import. Keep that compatibility; the fixture test in `tests/classic_format.rs` guards it. Masks and animations are raw JSON until ported.
  - `editor` (`opencut-editor`): headless `Editor`; every project change goes through a `Command` (`apply(&mut Project)`), undo/redo is snapshot-based and failed commands roll back. New edits are new commands, not direct mutation.
  - `media` (`opencut-media`): FFmpeg-backed media I/O. `setup/setup.ts` (`moon run media:setup`, a dep of `media:check`/`media:test`) downloads (or `--from-source` builds) the FFmpeg pinned in `setup/ffmpeg.json` (LGPL shared builds, sha256-verified) into `.cache/media/`; macOS has no pinned prebuilt yet, so it builds from source (a few minutes, once). `build.rs` links it, runs bindgen (needs libclang) over `wrapper.h` into the private `ffi` module, sets an rpath (copies DLLs into `OUT_DIR` on Windows), and exports `DEP_OPENCUT_FFMPEG_LIB_DIR` for dependents; `OPENCUT_FFMPEG_DIR` overrides the location. `format::Input` is the RAII `AVFormatContext` wrapper decoders build on; `probe()`/`probe_asset()` map a file into `MediaAsset`. Fixtures live in `tests/fixtures/`. Prebuilts come from `.github/workflows/media-deps.yml` (manual dispatch); bump versions in `ffmpeg.json`, not ad hoc.
- **Classic reference** — the classic app is at tag `pre-rewrite` (fetch it from `OpenCut-app/OpenCut`); read it with `git show pre-rewrite:<path>` when porting a feature. Don't check it out or merge it.
- **`brand/marks/`** — logo SVGs uploaded to the R2 bucket by `upload-logos`.

## Conventions

- Commits use Conventional Commits with scopes: `feat(desktop): …`, `ci(media): …`, `style(web): …`, `chore(tooling): …`.
- `.github/copilot-instructions.md` holds the Ultracite/Biome rule set for TS/JS (strict types, no `any`, no enums, no non-null `!`, `import type`, `for…of` over `forEach`, a11y rules, no `console`). Follow it in TS code, though no `biome.json` is committed yet so it isn't enforced by a task.
- External PRs aren't being accepted except for approved critical bug fixes.
